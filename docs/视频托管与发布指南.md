# 视频托管与 GitHub 发布指南（免费方案）

本项目约 **3.1 GB** 剧情视频，超出 GitHub **免费 LFS 配额**（约 1 GB），因此：

- **仓库里只保留代码**（HTML / CSS / JS / 剧情 JSON / 图片 / 音乐）
- **视频放在 GitHub Releases**（公开仓库免费，单文件最大 2 GB，足够用）

---

## 为什么不用夸克 / 百度网盘？

互动游戏在浏览器里用 `<video src="…">` 播放视频，需要 **可直接访问的文件直链**。

| 方式 | 能否用于本游戏 |
|------|----------------|
| 夸克 / 百度网盘分享页 | ❌ 是网页跳转，不是视频直链 |
| 阿里云 OSS / 腾讯云 COS | ✅ 专业 CDN，需少量费用 |
| **GitHub Releases** | ✅ **免费**，与 Pages 同一账号，最适合本项目 |

夸克网盘适合备份与分享，**不适合**作为网页游戏的视频源。

## 一、在 GitHub 创建 Release 并上传视频

### 1. 打开 Releases 页面

浏览器访问：

<https://github.com/Mon3tr-WoW/wandering-baby-plan/releases>

点击 **Draft a new release**（起草新发布）。

### 2. 填写标签（必须与代码一致）

| 字段 | 填写内容 |
|------|----------|
| **Choose a tag** | 输入 `videos-v1`，选 **Create new tag: videos-v1 on publish** |
| **Release title** | 例如：`剧情视频 v1` |
| **Description** | 可留空或写「流浪婴儿计划剧情视频包」 |

⚠️ 标签名必须是 **`videos-v1`**，与 `js/video-config.js` 里 `RELEASE_TAG` 一致。

### 3. 上传全部视频文件

在 **Attach binaries** 区域，把本地 `videos/` 文件夹里的 **全部视频**（当前约 **56 个**，含 A/B/C 线）全部拖进去。

上传前请在本机运行：

```powershell
python scripts/build-video-manifest.py
python scripts/validate-videos.py
```

`validate-videos.py` 会列出剧情引用但本地缺失的文件，请补全后再发布。

示例文件名（须与磁盘完全一致，区分大小写）：

```
1.mov  2.mov  …  10.mp4  A1.mp4  B10.1.mp4  C.mp4  …
```

- 总大小约 **5+ GB**（视素材而定），上传可能需 **30 分钟～数小时**
- **不要改文件名**
- **不要**上传 `README.md`；`data/video-manifest.json` 随代码 push，不必放进 Release

### 4. 发布

点击 **Publish release**。

### 5. 验证直链是否可用

在浏览器新标签页打开（应能下载或播放，而不是 404）：

```
https://github.com/Mon3tr-WoW/wandering-baby-plan/releases/download/videos-v1/1.mov
```

若打不开，检查标签名、文件名是否与上面一致。

## 三、提交并推送到 GitHub

```powershell
git add .
```

```powershell
git commit -m "改用 GitHub Releases 托管视频，解除 LFS 部署失败"
```

```powershell
git push origin main
```

推送成功后：

1. 打开仓库 **Actions** 标签
2. 等待 **Deploy to GitHub Pages** 出现绿色 ✓
3. 打开 **Settings → Pages**，查看网址，例如：  
   `https://mon3tr-wow.github.io/wandering-baby-plan/`

## 四、确认 Pages 视频能播

1. 用 **非 localhost** 打开 Pages 网址（或手机浏览器）
2. 进入游戏，播放到第一个剧情节点
3. 若黑屏：按 **F12 → Network**，看视频请求 URL 是否为  
   `github.com/.../releases/download/videos-v1/xxx.mov`  
   - **404**：Release 里缺文件或文件名不对  
   - **200 但不播**：换 Chrome / Edge 试；`.mov` 在部分旧浏览器可能需转 `.mp4`

本地开发仍用 `videos/` 文件夹，**无需** Release：

```powershell
python scripts/build-video-manifest.py
python -m http.server 8080
```

浏览器访问 `http://localhost:8080/` 即可（**不要**双击 `index.html` 用 file:// 打开）。

## 五、以后更新视频怎么办？

1. 在 GitHub **Releases** 新建标签，例如 `videos-v2`
2. 上传新视频包
3. 修改 `js/video-config.js` 里的 `RELEASE_TAG = 'videos-v2'`
4. `git commit` + `git push`，等 Actions 部署完成

## 六、常见问题

### Q：LLM 功能导致部署失败吗？

**不是。** 失败原因是 LFS 配额用尽；LLM 只是普通 JS，体积很小。

### Q：为什么以前能上传、现在不行？

以前可能只 push 了代码或小改动；当 Actions 尝试 **checkout 并下载全部 3.1 GB LFS 视频** 时，才触发配额上限。与是否更新 LLM 无关。

### Q：Release 上传太慢？

- 分批上传：先传 10 个，保存草稿，再编辑 Release 继续加文件
- 或安装 [GitHub CLI](https://cli.github.com/) 后用命令行上传（进阶）

### Q：Pages 打开黑屏，只剩右下角「与新人类对话」？

**原因：** 旧版 `llm.js` 强制 import 本地的 `llm-config.js`，该文件不会上传到 GitHub，导致整站 JS 加载失败。

**已修复：** 线上会自动回退到 `llm-config.example.js`，游戏可正常启动。更新代码后重新 `git push` 即可。

---

### Q：想换阿里云 OSS 可以吗？

可以。把 OSS 的公开读 URL 前缀写进 `js/video-config.js` 的 `RELEASE_BASE`（末尾保留 `/`），视频文件名规则不变即可。
