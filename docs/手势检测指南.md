# 手势检测指南

节点 **24**（地球 · 伸手）视频播完后，会自动弹出 **生物特征验证** 弹窗，通过摄像头 + MediaPipe 识别手势：

| 手势 | 剧情选项 | 跳转节点 |
|------|----------|----------|
| 手枪状（食指伸出，其余手指握拳） | 警惕 | 26 |
| 伸手 / 张开手掌（四指伸直） | 握上 | 27 |

保持同一手势约 **1 秒**，进度条填满后自动确认。

---

## 测试入口

开始界面右下角 → **手势实时检测**（在「与新人类对话」上方）

- 不推进剧情，仅测试摄像头与识别效果
- 需要浏览器允许 **摄像头权限**
- 建议使用 **Chrome / Edge**，且通过 **HTTPS** 或 `http://localhost` 访问

---

## 备用操作

1. **跳过手势检测** → 显示鼠标按钮
2. 约 **28 秒** 未识别成功 → 自动显示鼠标按钮
3. 手动点击 **警惕** / **握上** 与手势效果相同

---

## 技术说明

- 使用 Google **MediaPipe Hand Landmarker**
- WASM 从 jsDelivr / unpkg CDN 加载
- **手部模型优先使用仓库内本地文件** `assets/models/hand_landmarker.task`（约 7.5 MB），避免他人电脑因无法访问 Google 存储而导致「摄像头正常但无检测点」
- 若 GPU 推理无结果，约 4.5 秒后会自动切换 **CPU** 推理

### 若摄像头无法启动

- 确认网站为 HTTPS（GitHub Pages 可以）
- 本地请用：`python -m http.server 8080`，访问 `http://localhost:8080`
- 不要用 `file://` 直接打开 `index.html`

### 若摄像头正常但无手部检测点

1. 打开 F12 → **Console**，查看是否有红色报错
2. 确认状态栏是否显示 `检测就绪 · GPU/CPU · 本地模型`
3. 若显示 `CDN 模型` 且仍无检测：检查网络能否访问 `cdn.jsdelivr.net`
4. 确认 `assets/models/hand_landmarker.task` 已随项目一起部署（推送 Git 时不要漏掉）
5. 换 Chrome / Edge 再试；部分旧版 Firefox / Safari 对 WebGL WASM 支持较弱

在项目根目录打开 PowerShell：

```powershell
cd "C:\Users\Mon3tr\Desktop\GamePrograming\Mini works\wandering-baby-plan"

# 查看变更（应包含 js/gesture-detection.js 与 assets/models/hand_landmarker.task）

git push origin main
```

推送后：

1. 打开仓库 **Actions** 页，等待 **Deploy to GitHub Pages** 工作流变绿（约 1–2 分钟）
2. 访问 GitHub Pages 线上地址（Settings → Pages 中查看）
3. 让之前无法识别的同学 **强制刷新**（Ctrl+F5）后再测

**重要：** 本次修复必须把 `assets/models/hand_landmarker.task` 一并提交并推送，否则他人仍会走 Google CDN，国内部分网络可能依旧失败。

若本地还没有模型文件：

```powershell
Invoke-WebRequest -Uri "https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task" -OutFile "assets/models/hand_landmarker.task"
```
